# NovaSpace

Aplicación de escritorio desarrollada en **Python y PySide6** para el monitoreo de la salud cardiovascular y psicológica de astronautas durante misiones espaciales.

El sistema cuenta con dos módulos principales:

- **Astronautas:** visualización interactiva del estado de salud, monitoreo de signos vitales, asistente por voz y alertas de emergencia.
- **Médicos:** panel de monitoreo con indicadores de salud, análisis de tendencias, predicciones de riesgo, alertas y reportes médicos.

Su objetivo es facilitar el seguimiento de la salud de los astronautas, identificar posibles riesgos y apoyar la toma de decisiones médicas antes, durante y después de las misiones espaciales.
